{{- /* A page's display title. Microposts have none, so use their opening words (the ellipsis set against the last word: truncate's default puts a space before it, and year-page rows wrapped a lone "…"), then the date. Returns a string. Used for , og:title, Pagefind's title meta and llms.txt so they all agree. */ -}} {{- $t := .Title -}} {{- if and (not $t) .IsPage -}} {{- $t = .Summary | plainify | htmlUnescape | strings.TrimSpace | truncate 60 "…" -}} {{- if not $t }}{{ $t = (partial "local-date.html" .).Format "January 2, 2006" }}{{ end -}} {{- end -}} {{- return $t -}}
